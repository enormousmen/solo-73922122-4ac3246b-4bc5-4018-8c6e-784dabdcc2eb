LoadBalancer Local 接流核查器

上传同一批 NodeList、单个 Service 与 EndpointSliceList JSON 快照， 查看每个就绪节点上各 TCP 端口的接流状态。
仅支持 IPv4、externalTrafficPolicy=Local 的 LoadBalancer Service； 按命名空间、服务名与端口名关联切片，只看该节点的后端。
有 ready 后端 → 可接流；否则有 serving 且 terminating 的后端 → 仅终止兜底； 两者皆无 → 无可用后端；记录冲突且会改变结论 → 无法确认（列出冲突的 IP 与目标端口）。
